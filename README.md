# El-tumero Tap

## How do I install these formulae?

`brew install el-tumero/tap/<formula>`

Or `brew tap el-tumero/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "el-tumero/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
